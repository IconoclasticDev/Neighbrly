# Neighbrly web preview

Run `npm ci`, `npm run dev` or `npm run build`. The web app uses bundled demonstration fixtures in `shared/` and needs no backend to explore the user flows. Every score and report observation is invented; the sourced Mumbai ward boundaries do not validate report data. The Android-layout button changes preview width, not execution platform.

The monorepo download also includes native Android source, the Python report API, tests and setup instructions. The API is a local development starter and is not deployed as part of this static Site. Source attribution and Leaflet's license are retained in `THIRD-PARTY-NOTICES.md`.
